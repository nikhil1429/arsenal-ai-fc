```
services: 5/5 owned by the OS · …                                   (today's statusLine, unchanged)
  brain     RUNNING · booted <iso> · current (keeper retires on its own)
  sitting   RUNNING · booted <iso> · STALE — 2 file(s) moved after boot: scripts/gaffer_brain.mjs @<iso>, scripts/captains_call.mjs @<iso>

```

The computation, for a RUNNING unit `u` with entry `e(u)` (from `DAEMONS.args`):

```
boot(u)     = the unit's own boot instant, read from the unit (branch M2), never guessed
closure(u)  = brain.sourceGraph(e(u))           — the static + dynamic local import closure (scripts/brain.mjs:7063)
moved(u)    = brain.staleSources(closure(u), boot(u), statSync.mtimeMs)   — strict ">", no tolerance (brain.mjs:7090)
STALE(u)   ⇔ boot(u) known ∧ moved(u) ≠ ∅          · CURRENT ⇔ boot(u) known ∧ moved(u) = ∅ · else UNVERIFIED
```

Reusing `sourceGraph` / `staleSources` (exported) — not conductor's entry-only tier 1, which is the K6 defect.

## 4 · THE RESTART VERB

**Name:** `node scripts/services.mjs restart <unit> [--dry]` (branch M1 for the home). Inputs: one unit name.

**Who may run it, under which account:** it calls `sc.exe stop` then `sc.exe start` on `ArsenalFC-<unit>`; the SCM
accepts that from `.\arsenal-svc` (§2). So it is LAWFUL when run AS the service account — from inside a running unit
(the brain's keeper already runs as it) or a task registered under it. From his console it works only if his account
holds the right (UNREAD) — the verb never elevates, never asks for a password, never stores one.

**Refusals, each by name; every refusal changes nothing:**

| Refusal | Condition |
|---|---|
| `REFUSED NOT-OWN-UNIT` | `<unit>` is not one of the headless rows of `DAEMONS` (the logon tasks, or anything else) |
| `REFUSED NOT-INSTALLED` · `REFUSED NOT-RUNNING` | `sc query` reads no service / not RUNNING — **a stopped unit is never started** (the switch-off law: S12 turns things on, his word) |
| `REFUSED NOT-STALE` | §3 reads CURRENT — nothing to do (`--force-current` does not exist) |
| `REFUSED UNVERIFIED` | §3 cannot read the boot instant — a restart on a guess is refused |
| `REFUSED SITTING-OPEN` | an open sitting (§2 reader) — for every unit, since the sitting reads cortex, thalamus and the brain |
| `REFUSED JUDGE-RUNNING` | a judge round is running (a reader this unit adds, branch M4) |
| `REFUSED STUDY-LIVE` | a fresh forge session is open (captains_call's own rule, §2) |
| `REFUSED ACCESS-DENIED` | the SCM refused the stop or the start — named with its code, never retried in a loop |
| `RED STOPPED-NOT-STARTED` | the stop succeeded and the start did not — ONE card at his anchor (`captains_call.mjs file --key mlive:<unit>:<day>`), because a unit is now down |

After a start it re-reads §3 and prints `RESTARTED <unit> · booted <iso> · current` or names what is still stale.
